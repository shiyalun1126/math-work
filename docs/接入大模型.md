# 接入大模型：把密钥放进 `.env`

> 目标：填两个值，就能把自己拍的手写公式丢进去，得到 LaTeX、答案和讲解。
> 不想申请账号也能先玩：不填密钥时走内置样例（演示模式）。

---

## 一、四条通道各自干什么

| 通道 | 作用 | 免费额度 | 不给会怎样 |
|---|---|---|---|
| **SimpleTex** | 专用公式识别模型，把图变成 LaTeX | 官方标称累计 500/1000 次，**但开通开放平台需先充 ¥20**（押金性质，免费额度内不扣） | 少一路候选，用第三通道顶替即可 |
| **Qwen3-VL**（VLM） | 通用多模态模型，第一路识别 | 新用户每个模型 100 万 token / 90 天 | 识别能力大幅下降 |
| **第二路 VLM**（VLM2） | 换厂商的通用多模态，用于跨源投票 | 智谱 GLM-4.6V-Flash **永久免费**、免绑卡 | 退回单源，置信度上限 80% |
| **讲解模型** | 把已验算的步骤讲成人话 | 同上（可与 VLM 共用 key） | 只少一段讲评，其余功能不受影响 |

**至少要填一个 VLM。** 只填一个也能跑，但"多解投票"这一层就退化成单源自证，`review` 判定会明显变多——这是准确性的取舍，不是 bug。

为什么第二路一定要换厂商：投票有效的前提是**错误模式不相关**。同一家厂商的两个模型，训练数据和失效模式高度重合，凑在一起只是"自证清白"，系统会把 `independent` 判为 false，置信度照样压在 80%。跨厂商才算真正的交叉验证。

> **关于 SimpleTex 的 ¥20**：不是消费，是开通开放平台的门槛（官方用于防批量注册），在免费额度内使用不会扣这笔钱。如果不想垫，直接用下面智谱的免费 VLM 替代，效果不打折——它本身也是独立厂商。

## 二、`.env` 怎么填

文件已经建好在项目根目录，用记事本或 VS Code 打开：

```ini
SIMPLETEX_TOKEN=            ← 填这里（不想垫 ¥20 就留空）
SIMPLETEX_MODEL=standard    ← standard 更稳 / turbo 更快更便宜

DASHSCOPE_API_KEY=          ← 填这里
VLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
VLM_MODEL=qwen3-vl-plus

VLM2_API_KEY=               ← 第二路，填了才有跨源投票（智谱，永久免费）
VLM2_BASE_URL=https://open.bigmodel.cn/api/paas/v4
VLM2_MODEL=glm-4.6v-flash

LLM_API_KEY=                ← 留空就复用上面的 DASHSCOPE_API_KEY
LLM_MODEL=qwen-flash
ENABLE_EXPLAIN=1
```

保存即可，不用重启服务——界面上点「测试连接」会重新读取。

### 不想改文件？界面上也能填

打开 `http://127.0.0.1:7860`，左下角「密钥与连接（.env）」展开，两个密码框粘贴后点「保存到 .env」，程序会写回同一个文件（保留注释），下次启动照样生效。

### 密钥去哪拿

**SimpleTex**（约 2 分钟）

1. 打开 https://simpletex.cn ，用手机号注册
2. 右上头像 → 用户中心
3. 左侧「用户授权令牌」→ 创建一个 → 复制那串字符
4. 粘到 `SIMPLETEX_TOKEN=`

它给的是**累计**赠送，不是每月刷新：标准模型 500 次、轻量模型 1000 次，用完按 ¥0.05 / ¥0.04 一次计费。

**阿里云百炼**（约 3 分钟）

1. 打开 https://bailian.console.aliyun.com ，用支付宝/淘宝账号登录
2. 右上「API-KEY」→ 创建我的 API-KEY → 复制
3. 粘到 `DASHSCOPE_API_KEY=`
4. 首次使用要开通「模型服务」，在控制台点一下即可，不收费

新用户每个模型有 100 万 token 免费额度，`qwen3-vl-flash` 单张图约 800 token，够识别上万张。

## 三、验证是否通了

**方式一：界面**。展开「密钥与连接」，点「测试连接」，会真调一次接口：

```
- ✅ SimpleTex：可用，1.2s，自检图识别为 x^{2}-3x+2=0
- ✅ Qwen3-VL：可用，0.9s，模型 qwen3-vl-plus
- ✅ 讲解模型：可用，0.8s，模型 qwen-flash
```

**方式二：命令行**。

```bash
# 只打印配置（不花钱）
F:/PyCharm/python.exe tools/check_env.py

# 真调接口
F:/PyCharm/python.exe tools/check_env.py --probe

# 列出本账号实际可用的多模态模型
F:/PyCharm/python.exe tools/check_env.py --models

# 直接跑一张自己的照片
F:/PyCharm/python.exe tools/check_env.py --image 我的题.jpg
```

`--image` 会打印每一路候选、判定理由、选中结果、逐步解答和讲评，出问题时第一手信息都在这里。

### 模型名对不上是常事

阿里云会按账号、按时间开放不同的多模态模型。`qwen3-vl-flash` 在部分账号上不存在，
报错是"模型名不存在"；此时列表里可能只有 `qwen3-vl-plus`、`qwen-vl-ocr`。

所以模型名不要凭印象写，先跑 `--models` 看这一行：

```
可用的多模态模型
  qwen-vl-ocr
  qwen-vl-ocr-2025-11-20
  qwen3-vl-plus ← 当前使用
```

认准再写进 `.env` 的 `VLM_MODEL`。识别失败时程序也会把这行列表带进报错信息，
不用再去翻控制台。

顺带一提，`qwen-vl-ocr` 名字里带 ocr，但它需要专门的 task 指令，
用通用提示词会直接回 `NOMATH`，不适合当公式识别主力。

---

### 只有一把钥匙时会发生什么

只配 Qwen3-VL、不配 SimpleTex，系统仍然能跑，但它**不是**交叉验证：

| | 两个来源 | 只有一个来源 |
|---|---|---|
| 一致度的含义 | 两家独立模型互相印证 | 同一模型采样两次自一致 |
| 错误模式 | 不相关，票才有意义 | 高度相关，容易一起错 |
| 界面显示 | 「识别一致，可放心求解」 | 「识别完成（单源核对过）」+ 单源·无旁证 标签 |
| 置信度上限 | 100% | 80% |

压低上限不是谦虚，是实情：两次采样都对得上，只能说明模型对这一张图很"自信"，
不能说明它认对了。真正的旁证必须来自另一个厂商。

所以如果条件允许，`SIMPLETEX_TOKEN` 还是值得申请——免费额度 500–1000 次，
够把这套东西从头到尾验证一遍。

## 四、上传手写公式的正确姿势

| 情况 | 做法 |
|---|---|
| 一张照片只拍一行 | 直接传，程序自动摆正、裁边、放大 |
| 一张照片拍了整页（10 行） | **先切行**，别直接传 |
| 截图 / 微信里的图 | 直接传 |

整页切行：

```bash
F:/PyCharm/python.exe tools/split_page.py 我的照片.jpg --out data/crops --debug
```

产出 `我的照片_01.jpg` 到 `我的照片_10.jpg`，`--debug` 还会多出一张画红框的图，一眼能看出有没有切歪。

传整页会怎样：程序检测到"竖幅 + 多行"，在顶部弹黄色提示，然后仍然会把整幅当一个式子去认，结果通常是错的。这个提示不是拦你，是告诉你为什么结果不对。

拍摄要求（和 `docs/采集与切分方案.md` 一致）：

- 黑笔白纸，**上下两行的墨迹不要接触**（写大分式时格外注意）
- 手机正对纸面，别用扫描 App（会做透视校正和锐化，跟真实场景不一致）
- 光线均匀，别让手机影子压在字上

## 五、想换别家模型

只要能提供 OpenAI 兼容接口，改 `.env` 三行即可，**不用改代码**：

```ini
VLM_BASE_URL=https://api.siliconflow.cn/v1
VLM_API_KEY=sk-xxxx
VLM_MODEL=Qwen/Qwen3-VL-8B-Instruct
```

已验证可用的组合：

| 厂商 | base_url | 模型名 |
|---|---|---|
| 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 以 `--models` 输出为准 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen3-VL-8B-Instruct` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-5.3-flash` |

换模型后建议跑一次 `tools/check_env.py --probe`，确认模型名在你的账号里可用。

## 六、报错对照

| 现象 | 原因 | 处理 |
|---|---|---|
| `令牌无效（401）` | token 复制不全，或粘了首尾空格 | 重新复制，注意别把换行带进去 |
| `额度不足（402）` | SimpleTex 免费次数用完 | 把 `SIMPLETEX_MODEL` 改成 `turbo`，或去控制台买资源包 |
| `模型名可能不存在` | 模型 id 和你账号开通的不一致 | 按第五节表格改 `VLM_MODEL` |
| `图片过大或为空（413）` | 传了空文件或超大图 | 换一张；程序本来会压到 1280px |
| `网络不通：...` | 代理 / 防火墙 | 关掉系统代理重试，或确认能访问 `server.simpletex.cn` |
| 顶部提示"未配置密钥" | `.env` 没读到 | 确认文件名是 `.env` 不是 `.env.txt`（记事本会偷偷加后缀） |
| 两个通道都失败 | 通常是网络 | 先 `curl https://server.simpletex.cn` 看是否能通 |

最后一条最容易踩：Windows 记事本另存为时会在文件名后加 `.txt`，实际文件叫 `.env.txt`，程序找不到。在文件夹里打开"显示文件扩展名"确认一下。

## 七、花多少钱

| 项 | 估算 |
|---|---|
| 开发期调试（2000–5000 次调用） | ¥10–30 |
| 完整评测一轮（105 条 × 3 方法 × 5 采样） | ¥5–10 |
| 讲评（每次约 200 token） | 可忽略 |
| **合计** | **< ¥50** |

所有 API 结果按「图片 SHA256 + 模型 + 温度」缓存到 `.cache/`。改评测逻辑、改界面、重跑实验都不会重复计费——**这也是能做消融实验的前提**，否则两次调用的模型侧随机性不同，结果不可比。

缓存不需要手动清。真要重跑同一个样本，删 `.cache/` 即可。

## 八、两条安全提醒

1. **`.env` 已加进 `.gitignore`**，不会被提交。如果不小心提交了，去平台重置密钥——历史记录里的东西删不干净。
2. **别把密钥写进截图**。界面上的密钥是脱敏显示的（`abcd…wxyz`），但「保存到 .env」的输入框里是明文，投屏前先关掉这个面板。
