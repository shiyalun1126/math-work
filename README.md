# 手写数学批改 Agent

拍照上传学生的手写数学作业，逐行判断**每一步对不对**、错在哪一步、为什么错，而不是只给一个"答案对/错"。

面向的是题库检索路线最弱的那段区间：学生自己写的式子、写错的式子、题库里没有的式子。项目不追求"通用解题"，追求**限定域内的可信**——能力范围内每个结论可追溯，超范围就说超出范围。

## 能做什么

| 能力 | 说明 |
|---|---|
| 题目 → 答案 | 上传题目照片或输入 LaTeX，解析成语法树后求解，结果带分步过程。支持含参数方程（结果按 `branches` 分支给出）；含参二次还附七步**配方法推导**，从 `ax²+bx+c=0` 推到求根公式 |
| 过程 → 批改 | 上传整页或单行过程照片，逐行判定 `✓ / ✗ / 没认准`，指出第一处出错的位置并给出错因 |
| 认错就改 | 哪一行没认准，直接在页面上改成自己写的式子重判——不重拍、不重新识别 |
| 方程组批改 | 二元、三元都支持。不用"相邻两步解集是否相同"这种粗暴判据，而是逐行累积条件求 `linsolve`，区分"题给条件的变形"和"真的丢解/矛盾" |
| 三元方程组讲解 | 走教材的消元法：三元→二元→一元，逐步写出来源和抵消项，而不是直接甩一句"解得 (1,2,3)" |
| 因式分解诊断 | 能说清 `(x+1)(x-6)` 和原式差在哪一项，而不是只说"错了" |
| 几何题链路 | `geoagent` 处理三角形/圆的图形理解与条件推理，独立于代数链路 |
| 答案缓存 | 同题不重复调用模型，缓存键带版本号，改算法后自动失效 |
| 题目归档 | 搜过的题、批过的页按时间记下来，两个界面都能翻：完整版是「归档」页签，学生版是顶部第三个切换。系统没把握的步骤单独成区，等你看一眼。和错题本是两回事：[`docs/题目归档.md`](docs/题目归档.md) |

## 目录

```
mathagent/     代数链路：感知 → 切行 → 结构解析 → 求解 → 逐行批改 → 讲评
  perceive.py    多通道识别（SimpleTex / 通义 VL），带置信度
  lines.py       整页切行、裁框外扩
  equations.py   方程题型：提取、分类、求解、含参分支
  workcheck.py   过程批改核心：逐行判定、错因、反例
  verify.py      验算与语义等价判断
  history.py     题目归档：按时间记事件，摊出"待检查步骤"
  cases.py       错题本：按错因聚合，回答"我缺哪个动作"
geoagent/      几何链路：读图 → 关系抽取 → 推理 → 重绘比对
eval/          评测：用例集、指标、批量跑分
tools/         切页、拍前检查、样张生成、静态预览等脚本
app.py             完整批改台（默认 7860）
app_equation.py    方程题型调试台（7861）
app_student.py     学生端页面（7862）
```

## 跑起来

```bash
pip install -r requirements.txt
cp .env.example .env      # Windows: copy .env.example .env
```

`.env` 里至少填一条感知通道：`DASHSCOPE_API_KEY`（通义千问 VL，OpenAI 兼容端点）或 `SIMPLETEX_TOKEN`（公式识别专用）。讲解模型可选，留空则复用上面的 key。

```bash
python app.py            # 完整批改台  http://127.0.0.1:7860
python app_equation.py   # 方程题型    http://127.0.0.1:7861
python app_student.py    # 学生端      http://127.0.0.1:7862
```

## 测试与评测

```bash
pytest -q                       # 全部用例
python -m eval.run_eval         # 过程批改评测
python -m eval.run_photo_eval   # 真实拍照评测（需要自己按 data/shotlist.csv 拍）
```

`eval/` 下另有 `run_line_eval.py` 专门评估切行质量。评测报告写在 `reports/`，`_smoke_` 开头的是冒烟假数据，不是实测结果。报告 JSON 带全量逐块 `records`、`seed` 与输入指纹（标注/参数 sha256），指标可以只靠它复算；照片评测用 `--results` 指定结果快照，没有可用快照时退出码为 2（未执行），不当作通过。

## 边界

- 只做声明覆盖的题型（一元/二次方程、二元与三元一次方程组、代数化简、简单求导积分、限定三角形与圆的图形）；不在范围内的题会明确报超出。
- **算不动的题会当场说停**：嵌套根式（根号里套根号）、8 秒内求不出闭式解的方程，返回「超出范围」而不是让页面空转。这类题一般确实没有初等解法，继续算只是在消耗你的耐心。
- 识别有把握才判错。手写连笔、涂改、出框的字符会被标成"没认准"交给人工，而不是硬猜一个结论。
- 单题连续三次无法判定就停下来问人，不硬答。

## 数据与隐私

作业**原图**不进仓库：`data/inbox*`、`data/work/`、`data/crops/`、`data/raw/`、`data/test/`
均已忽略；下载的第三方数据集（`data/public/`，多为非商业许可）也不进。`fixtures/`
里保留的是程序生成的样张（`tools/make_*.py` 可复现）。

**但原图被忽略不等于整仓脱敏。** 拍照链路会把同一张作业的另一种形态留在别处：
`reports/p0_*.jpg` 是八页实拍的拼贴与切行检查图，`data/photo_results_v*.jsonl`
含逐行识别文本和判定结果；错题本 `data/cases.jsonl` 每条含题目原文和学生答案；
归档 `data/history.jsonl` 还多记了"什么时候搜过哪道题"——它本身就是一份学习行为日志。
这些能还原出"谁写了什么、错在哪"，所以单独登记、单独核发布权。

- 清单：`data/assets.csv`（每张图/每份快照的来源与授权状态）
- 检查：`python tools/check_assets.py`（`--strict` 把未核实的项当失败）
- 说明：[`docs/资产来源与授权.md`](docs/资产来源与授权.md)

现存 5 张实拍衍生图与 1 组识别文本快照（`data/photo_results_v*.jsonl`）已登记来源：
手写内容为自己与家人写的练手题，图内无姓名/学号/学校，已确认可公开。
新增这类资产必须先在表里登记，否则 CI 会红。
